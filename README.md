#### 1. Реализация функции CAPTCHA

**Дизайн страницы с CAPTCHA:**

<img width="840" height="740" alt="Image" src="https://github.com/user-attachments/assets/a70c71b6-4918-4b9a-93c5-3af1efe250ac" />

**Основные элементы интерфейса (WPF):**
* ``Border`` - красивая рамочка для визуального отделения полей от страницы
* ``TextBlock`` - подписи к полям ввода и заголовок страницы
* ``TextBox`` - поля ввода имени пользователя и CAPTCHA
* ``PasswordBox`` - поле ввода пароля
* ``Button`` - кнопки, отвечающие за обработку событий входа, ввода/обновления CAPTCHA

**Основные методы и функции:**
1. ``enter_Click(object sender, RoutedEventArgs e)`` — обработчик кнопки входа. В нём:
  * проверяется корректность данных
  * ищется пользователь в базе данных (``Core.Context.Users.FirstOrDefault``)
  * сравнивается введённый пароль с сохранённым
  * ведётся подсчёт неудачных попыток входа, и при достижении 3х вызывается метод ``ShowCaptcha()``

2. ``GenerateCaptcha()`` — основной метод генерации изображения CAPTCHA:
  * используется Random для случайного выбора символов и генерации шума
  * создаётся ``DrawingVisual`` и ``DrawingContext`` для рисования:
    - фон — ``DrawRectangle`` с цветом
    - пятна — ``DrawEllipse`` с полупрозрачными светлыми цветами
    - линии — ``DrawLine`` с разнонаправленными и цветными линиями
    - текст CAPTCHA — ``DrawText`` с ``FormattedText``, случайный угол наклона через ``RotateTransform``
    - точки шума — ``DrawEllipse`` с маленькими случайными эллипсами

  * результат рендерится в RenderTargetBitmap и преобразуется в BitmapImage через метод ``ToBitmapImage()``

**Используемые функции:**
* ``Color.FromRgb`` / ``Color.FromArgb`` для задания цветов
* ``SolidColorBrush``, ``Pen``, ``Point``, ``Rect`` для графики
* ``Random`` для генерации случайных значений
* ``PushTransform`` / Pop для наклона текста
* ``FormattedText`` для форматирования символов


#### 2. Автоматизированное тестирование с использованием unit-тестов 

**Автотесты методов класса ```CaptchaLogic```:**

<img width="1360" height="450" alt="image" src="https://github.com/user-attachments/assets/62a6038b-ef4e-4e47-8303-b7972e2209ee" />


```RegisterFailedPasswordAttempt_ChangesLastFailedLoginOnlyWhenDifferentUser```  
Проверяет, что поле `lastFailedLogin` обновляется только при смене логина пользователя, а при повторных неудачных попытках одного и того же пользователя значение остаётся прежним.  
**Результат:** тест проходит успешно. Логика запоминания последнего неудачного логина работает корректно.

```ShouldShowCaptcha_BecomesTrueExactlyOnThirdAttempt```  
Проверяет пороговую логику показа капчи: после 0, 1 и 2 неудачных попыток метод `ShouldShowCaptcha()` возвращает `false`, а после третьей попытки — `true`.  
**Результат:** тест проходит успешно. Механизм срабатывания капчи после ровно трёх ошибок реализован верно.

```ShouldShowCaptcha_AfterTwoFailedAttempts_ReturnsFalse```  
Проверяет, что после двух неудачных попыток капча ещё не показывается.  
**Результат:** тест проходит успешно. Подтверждает корректность порогового значения.

```GenerateCaptchaText_ContainsConfusingCharacters_ShouldFailBy1```  
Проверяет, что в сгенерированном тексте капчи никогда не встречаются неоднозначные символы `O`, `0`, `I`, `l`, `1`.  
**Результат:** тест не проходит. Символ `1` не был исключён из  набора символов на капчу, поэтому возникает путаница.

```GenerateCaptchaText_ShouldContainDigitAndSpecialChar_FailInMostCases```  
Проверяет, что в большинстве сгенерированных капч присутствует хотя бы одна цифра и хотя бы один спецсимвол. Допускается не более 25% капч без цифр и не более 50% без спецсимволов.  
**Результат:** тест часто не проходит. Это указывает на уязвимость: в значительном проценте случаев капча генерируется без цифр или без спецсимволов.

```IsCaptchaCorrect_CaseSensetiveCaptcha_ShouldFail```  
Проверяет чувствительность проверки ввода к регистру символов. Ожидается, что капча пройдёт только при точном совпадении регистра.  
**Результат:** тест не проходит. В метод передана капча в другом регистре, что вызывает сбой.

```IsCaptchaCorrect_WrongUserInput_ReturnsFalse```  
Проверяет, что при вводе заведомо неверной строки метод возвращает `false`.  
**Результат:** тест проходит успешно. Базовая негативная проверка работает корректно.

```GenerateCaptchaText_CreatesNewTextAfterReset_ReturnsTrue```  
Проверяет, что после вызова метода `Reset()` при последующей генерации капчи текст становится другим (состояние полностью очищается).  
**Результат:** тест проходит успешно. Сброс состояния реализован правильно, капча не повторяется.
