**Основные элементы интерфейса (WPF):**
* ``Border`` - красивая рамочка для визуального отделения полей от страницы
* ``TextBlock`` - подписи к полям ввода и заголовок страницы
* ``TextBox`` - поля ввода имени пользователя и CAPTCHA
* ``PasswordBox`` - поле ввода пароля
* ``Button`` - кнопки, отвечающие за обработку событий входа, ввода/обновления CAPTCHA

**Основные методы и функции:**
1. ``enter_Click(object sender, RoutedEventArgs e)`` — обработчик кнопки входа. В нём:
  * проверяется корректность данных
  * ищется пользователь в базе данных (``Core.Context.Users.FirstOrDefault``)
  * сравнивается введённый пароль с сохранённым
  * ведётся подсчёт неудачных попыток входа, и при достижении 3х вызывается метод ``ShowCaptcha()``

2. ``GenerateCaptcha()`` — основной метод генерации изображения CAPTCHA:
  * используется Random для случайного выбора символов и генерации шума
  * создаётся ``DrawingVisual`` и ``DrawingContext`` для рисования:
    - фон — ``DrawRectangle`` с цветом
    - пятна — ``DrawEllipse`` с полупрозрачными светлыми цветами
    - линии — ``DrawLine`` с разнонаправленными и цветными линиями
    - текст CAPTCHA — ``DrawText`` с ``FormattedText``, случайный угол наклона через ``RotateTransform``
    - точки шума — ``DrawEllipse`` с маленькими случайными эллипсами

  * результат рендерится в RenderTargetBitmap и преобразуется в BitmapImage через метод ``ToBitmapImage()``

**Используемые функции:**
* ``Color.FromRgb`` / ``Color.FromArgb`` для задания цветов
* ``SolidColorBrush``, ``Pen``, ``Point``, ``Rect`` для графики
* ``Random`` для генерации случайных значений
* ``PushTransform`` / Pop для наклона текста
* ``FormattedText`` для форматирования символов
